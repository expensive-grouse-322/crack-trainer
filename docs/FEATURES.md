# CRACK Trainer — feature reference

CRACK Trainer focuses on three connected areas: session settings, profile groups, control reference. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Session settings | Session and activity information grouped by the task or context it belongs to. |
| Profile groups | Related settings collected into named groups for a clearer configuration workflow. |
| Control reference | A dedicated section for control reference and the configuration details associated with that area. |

The project page follows the same section structure.
